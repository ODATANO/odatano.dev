# Get Started

ODATANO is an OData V4 API for public blockchains. ODATANO covers Cardano, NIGHTGATE covers Midnight, ASTRA adds analytics over both. Four ways in:

| Way | What you need | Start here |
|-----|---------------|------------|
| **Hosted API** | one key from the [API page](https://api.preprod.odatano.dev/) | [Hosted API](#hosted-api) |
| **AI agents** | the same key in your MCP client | [AI agents](#ai-agents-mcp) |
| **SAP CAP plugin** | `npm install` into your CAP app | [ODATANO](#odatano-as-a-cap-plugin) and [NIGHTGATE](#nightgate-as-a-cap-plugin) |
| **Standalone** | the repo or the Docker image | [Standalone](#standalone) |

Hosted and self-hosted serve the same routes. Integrate against the hosted API first, move to your own instance later without changing a path.

## Hosted API

ODATANO, NIGHTGATE and ASTRA run at [api.preprod.odatano.dev](https://api.preprod.odatano.dev/) behind one key. Cardano preprod and Midnight preprod, nothing to install.

### 1. Get a key

Sign in with a Cardano wallet on the [API page](https://api.preprod.odatano.dev/). The first key comes with free calls. Codes and packs paid with ADA over x402 add more.

### 2. Call it

The key goes as a bearer token. Cardano:

```bash
curl https://api.preprod.odatano.dev/odata/v4/cardano-odata/NetworkInformation \
  -H "Authorization: Bearer oda_..."

curl -X POST https://api.preprod.odatano.dev/odata/v4/cardano-transaction/BuildSimpleAdaTransaction \
  -H "Authorization: Bearer oda_..." \
  -H "Content-Type: application/json" \
  -d '{"senderAddress":"addr_test1...","recipientAddress":"addr_test1...","lovelaceAmount":10000000}'
```

Midnight and analytics, same key:

```bash
curl "https://api.preprod.odatano.dev/odata/v4/nightgate/Blocks?\$top=1" \
  -H "Authorization: Bearer oda_..."

curl https://api.preprod.odatano.dev/odata/v4/astra/ChainOverview \
  -H "Authorization: Bearer oda_..."
```

Every forwarded call is listed with an example response in the [API reference](https://api.preprod.odatano.dev/reference). Routes, key lanes and limits: [Hosted API](/docs/api/).

## AI agents (MCP)

Two MCP servers put both chains in front of an agent. One `.mcp.json` for Claude Code, Claude Desktop, Cursor or any MCP client:

```json
{
  "mcpServers": {
    "odatano": {
      "command": "npx",
      "args": ["-y", "@odatano/core-mcp"],
      "env": { "ODATANO_ACCESS_KEY": "oda_..." }
    },
    "nightgate": {
      "command": "npx",
      "args": ["-y", "@odatano/nightgate-mcp"],
      "env": { "ODATANO_ACCESS_KEY": "oda_..." }
    }
  }
}
```

The gateway is the default URL. The agent reads, builds and verifies; a human, a wallet or a sponsor signs. Tools and flows: [MCP servers](/docs/mcp/).

## ODATANO as a CAP plugin

`@odatano/core` is a SAP CAP plugin for Cardano. It exposes blocks, addresses, UTxOs and pools as OData entities and builds transactions as OData actions. Needs Node.js 22.5 or newer and `@sap/cds` 10.

Without a CAP project yet:

```bash
npm i -g @sap/cds-dk
cds init my-app && cd my-app
```

### 1. Install

```bash
npm install @odatano/core @cap-js/sqlite
```

### 2. Configure

In `package.json`:

```json
{
  "cds": {
    "requires": {
      "[development]": { "auth": { "kind": "dummy" } },
      "db": { "kind": "sqlite", "credentials": { "url": "db.sqlite" } },
      "odatano-core": {
        "network": "preview",
        "backends": ["blockfrost", "koios"]
      }
    }
  }
}
```

The Blockfrost key goes into `.env`, not into `package.json`:

```bash
BLOCKFROST_API_KEY=preview_your_api_key
```

Get a free key at [blockfrost.io](https://blockfrost.io). The `[development]` auth block lets `cds watch` accept requests without a JWT.

### 3. Run

```bash
cds deploy --to sqlite
cds watch
```

Six services register under `/odata/v4/cardano-*`. First request:

```bash
curl http://localhost:4004/odata/v4/cardano-odata/NetworkInformation
```

Services, transactions, Plutus and configuration: [ODATANO guide](/docs/odatano/).

## NIGHTGATE as a CAP plugin

`@odatano/nightgate` is the plugin for Midnight: a block indexer plus a wallet stack for ZK-aware transaction submission. Shielded transfers, Compact contracts, document anchoring and zero-knowledge attestations.

### 1. Install

```bash
npm install @odatano/nightgate @cap-js/sqlite
```

### 2. Configure

```json
{
  "cds": {
    "requires": {
      "db": { "kind": "sqlite" },
      "nightgate": { "network": "preprod" }
    }
  }
}
```

`network` is the only required key. Defaults: public preprod RPC, hosted Midnight indexer, in-process proving.

### 3. Run

```bash
cds watch
```

Five services register under `/api/v1/*`. Write actions are async: they return a job id, you poll `getJobStatus`. Services, wallet sessions, proofs and configuration: [NIGHTGATE guide](/docs/nightgate/).

### Both in one app

The two plugins are independent CAP requires. One app serves Cardano and Midnight side by side:

```json
{
  "cds": {
    "requires": {
      "db": { "kind": "sqlite" },
      "odatano-core": { "network": "preview" },
      "nightgate": { "network": "preprod" }
    }
  }
}
```

## Standalone

Without a CAP project of your own, each repo runs as its own service on port 4004, with the same routes as the plugin.

```bash
git clone https://github.com/ODATANO/ODATANO && cd ODATANO
npm ci && cp .env.example .env      # NETWORK, BACKENDS, BLOCKFROST_API_KEY
cds deploy --to sqlite && cds serve
```

```bash
docker run -d --name nightgate -p 4004:4004   -e ENCRYPTION_KEY=$(openssl rand -hex 32)   -e NIGHTGATE_HTTP_PASSWORD=change-me   -v nightgate-data:/data   ghcr.io/odatano/nightgate:latest
```

Docker for ODATANO, the local cardano-node stack and production set-ups: [ODATANO](/docs/odatano/#run-it) and [NIGHTGATE](/docs/nightgate/#run-it).
